# Contribuer / Contributing

Merci de ton intérêt ! / Thank you for your interest!

## Façons de contribuer
1. **Ajouter des phrases** : ajoute des lignes dans `data/sentences.csv` (colonnes : `id, ewe, french, english, source, validated`).
2. **Relire** : vérifie les traductions et signale les erreurs via une *issue*.
3. **Documenter** : améliore le README ou la datasheet.

## Règles simples
- Écris l'éwé en **UTF-8** avec les caractères corrects (ɖ, ɛ, ƒ, ɣ, ŋ, ɔ, ʋ) et les marques de ton si tu les utilises. Sois cohérente dans tout le fichier.
- Indique la variante/dialecte dans la colonne `source` si tu la connais.
- **Pas de données personnelles** (noms complets, numéros de téléphone, adresses) dans les phrases.
- **Pas de contenu protégé par le droit d'auteur** (paroles de chansons, extraits de livres, articles copiés). N'ajoute que des phrases que tu as écrites toi-même ou issues de sources sous licence ouverte compatible.
- Garde un ton respectueux : pas de contenu haineux ou offensant.

## Comment proposer une contribution (débutant·e)
1. Clique sur **Fork** (en haut à droite) pour copier le dépôt dans ton compte.
2. Modifie le fichier directement sur GitHub (icône ✏️).
3. Clique sur **Commit changes**, puis **Contribute → Open pull request**.
4. Décris brièvement ce que tu as changé.

Pas sûr·e de toi ? Ouvre une *issue* et pose ta question, tout le monde débute un jour. 💚
